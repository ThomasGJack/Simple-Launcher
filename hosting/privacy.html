Politique de confidentialité

Dernière mise à jour : 30 avril 2026

Cette politique explique quelles données personnelles Simple Launcher collecte, pourquoi, où elles sont stockées, et quels sont tes droits. Le launcher est conforme au RGPD (UE 2016/679).

TL;DR — on collecte le minimum nécessaire pour faire fonctionner le launcher (ton profil Discord, tes statistiques de jeu, tes messages avec d'autres users). Aucune publicité, aucune revente de données, aucun tracker tiers. Tes identifiants Microsoft ne transitent jamais par nous.

1. Responsable du traitement

Simple Launcher est un projet personnel développé par un particulier en France. Pour toute question concernant tes données, contacte le développeur via le serveur Discord ou via les paramètres du launcher.

2. Données collectées

Voici la liste exhaustive des données que le launcher stocke :

DonnéeSourceFinalité
UID Discord OAuth Discord Identifier ton compte de manière unique
Pseudo + avatar Discord OAuth Discord Affichage dans la communauté, messages, sessions
UUID Minecraft + pseudo MC OAuth Microsoft (si tu connectes un compte MC) Lancer les modules Minecraft avec ton compte
Statistiques de jeu Mesurées localement Affichage profil + classement amis
Messages (DM, clan, sondages) Saisis par toi Communication entre utilisateurs
Présence (en ligne, lastSeen) Mesurée par le launcher Surface aux amis (désactivable)
Logs techniques Générés par le launcher Diagnostic bugs, rétention 7 jours
Préférences (thème, RAM, favoris) Saisies par toi Personnalisation

3. Ce que nous NE collectons PAS

  • Pas d'email — OAuth Discord/Microsoft, on ne voit jamais ton email
  • Pas de mot de passe — l'auth passe par les pages officielles, dans ton navigateur
  • Pas de carte bancaire — le launcher est gratuit
  • Pas de tracker tiers — pas de Google Analytics, pas de Facebook Pixel, pas de Sentry
  • Pas de scan de fichiers — accès uniquement aux dossiers d'instances de jeu créés par le launcher
  • Pas de données biométriques, religieuses, politiques, médicales

4. Authentification Microsoft / Minecraft

Quand tu connectes un compte Microsoft pour Minecraft :

  • La fenêtre de login est celle de Microsoft, ouverte dans ton navigateur — pas dans le launcher
  • Microsoft nous renvoie un jeton d'accès Minecraft et ton UUID/pseudo de jeu
  • Le jeton est stocké localement dans Windows Credential Manager, jamais sur nos serveurs
  • Tu peux te déconnecter à tout moment depuis les paramètres du launcher → le jeton est supprimé immédiatement

5. Où sont stockées tes données

Les données du launcher sont hébergées sur Firebase (Google Cloud), dans la région europe-west1 (Belgique). Cela inclut :

  • Firestore : profil, messages, présence, statistiques
  • Firebase Storage : avatars, bannières, fichiers de logs
  • Firebase Auth : session de connexion (lié à ton OAuth Discord)

Les jetons Microsoft / Mojang sont uniquement stockés sur ta machine locale (coffre-fort OS) — jamais sur Firebase.

6. Durée de conservation

Profil + statistiquesConservés tant que ton compte existe
Messages privés (DM)Conservés tant que la conversation existe
Logs techniques7 jours, puis suppression automatique
Présence (lastSeen)Mise à jour en continu, pas d'historique
Compte suppriméEffacement complet sous 30 jours

7. Tes droits (RGPD)

Tu as le droit de :

  • Accès — consulter toutes tes données depuis ton profil dans le launcher
  • Rectification — modifier ton bio, banner, pseudo, etc. depuis ton profil
  • Effacement — demander la suppression complète de ton compte
  • Portabilité — récupérer tes données sous forme de JSON sur demande
  • Opposition — refuser certains traitements (ex. masquer ta présence aux autres users)
  • Réclamation — déposer une plainte auprès de la CNIL en France

8. Cookies et stockage local

Le launcher (application Windows) utilise le stockage local pour mémoriser :

  • Ta session OAuth Discord
  • Tes jetons Microsoft (chiffrés)
  • Tes préférences (thème, RAM Minecraft, favoris)

La page web (simplelaunche.web.app) ne dépose aucun cookie de tracking. Seulement les cookies fonctionnels stricts si tu te connectes pour voir ton profil partageable.

9. Partage des données

Tes données ne sont jamais vendues, jamais louées, jamais partagées avec des annonceurs. Elles sont uniquement visibles par :

  • Toi-même
  • Les autres utilisateurs du launcher (selon tes réglages de confidentialité)
  • Le développeur du launcher (admin) à des fins de debug et modération
  • Les sous-traitants techniques nécessaires (Google Firebase) sous contrat

10. Sécurité

  • Communication chiffrée HTTPS / TLS 1.3 avec tous les services tiers
  • Règles d'accès Firestore restrictives — tu ne peux lire/modifier que tes propres données
  • Jetons Microsoft chiffrés via le coffre-fort OS
  • Mises à jour de sécurité régulières via l'auto-updater Tauri

11. Mineurs

Le launcher est destiné aux utilisateurs de 13 ans ou plus (limite minimale de Discord). Les comptes Microsoft de mineurs nécessitent une autorisation parentale via Microsoft Family Safety pour fonctionner avec Minecraft.

12. Modifications de cette politique

Cette politique peut être mise à jour. La version en vigueur est toujours celle accessible à simplelaunche.web.app/privacy.html. Une notification dans le launcher préviendra des changements majeurs.

13. Contact

Pour toute question, demande d'accès ou suppression de données, contacte le développeur via le serveur Discord du launcher ou via les paramètres du launcher (« Signaler un problème »).
