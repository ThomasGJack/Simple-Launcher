⚠ Windows affiche "Cette application n'est pas reconnue" ?

Normal — le launcher est signé pour les auto-updates mais pas avec un certificat payant Microsoft (~300 €/an). Windows met en garde sur tout .exe peu téléchargé.

  1. Sur l'écran bleu "Windows a protégé votre ordinateur", clique "Informations complémentaires".
  2. Un bouton "Exécuter quand même" apparaît en bas — clique dessus.
  3. L'install démarre normalement. Tu n'auras à le faire qu'une fois.

Toutes les mises à jour suivantes passent automatiquement sans cette popup, parce qu'elles sont vérifiées par signature ed25519 directement dans le launcher.

Sous le capot

Léger, signé, et pas un Electron.

Construit en Tauri (Rust + WebView natif), pas en Electron. Résultat : un installer de 5 MB et un footprint mémoire à un chiffre.

simple-launcher.exe
# Auto-update flow au lancement [updater] Checking https://simplelaunche.web.app/launcher/win/releases.win.json [updater] Found v26.05.06.16 (current: v26.05.06.15) [updater] Delta package detected ("3.2 MB") — skipping full [updater] Verifying ed25519 signature… OK [updater] Applying update atomically + restart [updater] Done. # Connexion Discord → crew Simple Games [auth] Discord OAuth → loopback "http://localhost:14257/callback" [auth] Custom token signed by Cloud Function "discordAuth" [crews] Adding user to master crew "Simple Games"… OK → Bienvenue dans le crew.
Backend Rust + Tauri 2

Tout le launch path Minecraft, l'installeur de redistributables VC++, la gestion Java et le tray vivent en Rust. Tauri pour le pont avec la WebView native (Edge sur Win11, pas un Chromium dans la boîte).

UI React 19 + Tailwind 4

UI moderne avec Framer Motion pour les transitions, Zustand pour l'état, GSAP/tsParticles pour les particules. Tout le frontend est code-splitté (lazy routes).

Cloud Firebase + Velopack

Firestore pour les modules, profils, achievements et le crew. Storage pour les assets, Hosting CDN pour l'auto-update Velopack (delta packages ~3-5 MB / release au lieu de full). Cloud Functions pour Discord OAuth et webhooks Ko-fi.

FAQ

Les questions qu'on nous pose.

★ C'est quoi Simple Games exactement ?

Simple Games c'est le crew (la communauté) qui vit à l'intérieur de Simple Launcher. Techniquement c'est un master crew dans le launcher — un clan Discord-style auquel tous les utilisateurs sont auto-membres dès leur premier login. Tu n'as rien à faire pour le rejoindre, et tu ne peux pas le quitter.

C'est l'endroit où on parle des modpacks, où on annonce les events, où on partage des screenshots, où on fait des sondages. Comme un Discord serveur principal, sauf que c'est intégré au launcher donc pas besoin de jongler entre 2 apps.

★ Je peux créer mon propre crew, séparé de Simple Games ?

Oui — tout utilisateur ayant un tier Soutien / VIP / Légende (via Ko-fi) peut créer ses propres crews privés ou publics. Tu choisis emblème, couleur, channels, rôles custom, code d'invitation. Simple Games reste accessible en parallèle, c'est pas l'un ou l'autre.

Les crews publics sont listés dans la section "Découvrir" — n'importe qui peut les rejoindre. Les privés se rejoignent uniquement via code d'invitation que tu partages.

Pourquoi Windows me dit "Cette application n'est pas reconnue" ?

Le launcher est signé numériquement pour la vérification d'auto-updates (ed25519), mais pas avec un certificat Microsoft Code Signing commercial (~300 €/an), donc SmartScreen marque chaque .exe peu téléchargé comme suspect par défaut.

Sur l'écran bleu, clique "Informations complémentaires" puis "Exécuter quand même". Une fois installé, les mises à jour suivantes passent en silence — elles sont validées par signature directement dans le launcher, sans intervention de Windows.

Comment on importe un modpack Minecraft ?

Trois sources possibles, configurables côté admin du module :

CurseForge — colle l'ID du projet, le launcher pull la dernière version
Modrinth — colle l'URL du .mrpack
ZIP manuel — héberge un .zip CurseForge-style et colle l'URL

Le launcher détecte la version Minecraft + le loader (Fabric/Forge/NeoForge) depuis le manifest du modpack et installe tout automatiquement (mods, configs, resourcepacks, shaderpacks).

Mes données restent-elles privées ?

Oui. Le launcher ne collecte aucune donnée à des fins commerciales. Les seules choses qui partent côté serveur :

• Login Discord (OAuth, ton id Discord et avatar)
• Login Microsoft (uniquement pour Minecraft, géré par Microsoft directement)
• Achievements et stats de jeu (uniquement si tu joues à un module qui les active)
• Présence Discord (si tu actives le Rich Presence)

Tous les tokens d'auth sont stockés dans Windows Credential Manager côté local, jamais en clair dans un fichier. Les détails sont sur la page de confidentialité.

Mac ou Linux ?

Pas pour l'instant. Le launcher est Windows-only car le runtime Tauri qu'on utilise dépend de la WebView native de chaque OS, et plein de chemins critiques (auto-install des redistributables VC++, hooks Discord RPC, tray Win32) sont écrits côté Windows.

Un portage est techniquement possible mais pas dans la roadmap court terme. Ouvre une issue si ça t'intéresse !

Quelle RAM allouer pour Minecraft moddé ?

Pour un modpack moderne (~100 mods avec Sodium + Iris + Distant Horizons) : 4 à 8 GiB. Moins que 4 GiB tu vas voir des freezes GC, plus que 8 c'est rarement utile et ça peut même nuire aux temps de pause GC.

Dans Simple Launcher, chaque utilisateur peut override la RAM par module et par machine sans toucher au réglage admin partagé. Le slider est sur la page de chaque module Minecraft.

C'est open-source ? Comment je contribue ?

Le projet est privé à ce stade — pas de repo public ni de mécanisme de PR pour l'instant. Si t'es intéressé pour bosser dessus ou rapporter un bug, contacte le crew directement depuis les channels Simple Games dans le launcher.

Combien d'espace disque ça prend ?

Le launcher seul : ~30 MB installé. Chaque module Minecraft pèse ce que pèse son modpack (souvent 1 à 4 GiB avec mods + assets téléchargés). Le launcher partage les libraries entre instances quand c'est possible (libraries Java vanilla, assets Mojang).

Tu peux désinstaller un module à tout moment, ça libère le disque proprement.

Prêt à rejoindre le crew ?

Installer signé, ~5 MB, Windows 10/11. Tu rejoins Simple Games automatiquement à ton premier login Discord. Auto-update activé. Désinstallable proprement à tout moment.
